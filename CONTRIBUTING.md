# Как работать вместе над SubWise AI

## Простыми словами

Репозиторий — это общая папка в облаке (GitHub). Ты и Ася работаете каждый у себя на компьютере, а изменения синхронизируете через GitHub.

**Правило:** не пишем в main напрямую. Каждый делает свою ветку → проверяем → сливаем.

## Шаги для Аси (первый раз)

```bash
# 1. Клонировать репо
git clone https://github.com/abuten1977-design/subwise-ai.git
cd subwise-ai

# 2. Создать свою ветку
git checkout -b asya/fix-something

# 3. Работать (менять файлы, писать код)
# ... Claude Coder помогает ...

# 4. Сохранить изменения
git add -A
git commit -m "описание что сделала"

# 5. Отправить на GitHub
git push origin asya/fix-something

# 6. Создать Pull Request на GitHub (или через CLI: gh pr create)
```

## Шаги для Андрея

```bash
# 1. Забрать свежие изменения
cd /tmp/subwise-ai
git pull

# 2. Посмотреть что Ася сделала
gh pr list

# 3. Проверить и слить
gh pr merge <номер>

# 4. Задеплоить
bash deploy.sh
```

## Правила

1. **Одна задача = одна ветка.** Не мешаем всё в кучу.
2. **Имена веток:** `asya/что-делаю` или `andrey/что-делаю`
3. **Перед работой:** `git pull origin main` — забрать свежее
4. **Коммиты:** короткое описание на русском или английском
5. **Не ломать main:** если не уверен — спроси перед мержем
